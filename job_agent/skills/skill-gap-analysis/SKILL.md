调用 skill_gap_analysis。
列出简历已有证据支持的岗位相关能力，不把关键词出现当作熟练。
优先准备未覆盖的必需技术，再考虑加分项。
明确列出最先处理的三项：先必需后加分，同级先明确差距、再学习中、最后待确认。
明确不会和学习中的技能列入学习差距；没写证据的技能先请用户确认或补充真实项目证据。
学历、专业和工作经验不满足或未确认时单独列出，不声称做项目就能满足硬性要求。
建议包含具体练习、可检查的产出和验收方式；能复用现有 Platform 时优先复用。
仅返回建议，不自动修改用户简历、安装依赖、调用付费 API 或投递。
