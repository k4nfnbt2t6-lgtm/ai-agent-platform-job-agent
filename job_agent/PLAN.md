# Job Agent v1：结构盘点与实施计划

业务代码位于 `job_agent/`，Platform 继续位于 `agent_platform/`。不复制 SDK 循环、会话、模型客户端或费用控制，不移动原模块。

复用：PlatformRuntime（通过业务配置方法扩展）、PlatformRecorder、ContextSession/SQLiteSession、read_line、凭据检查、SkillCatalog。业务权限不包含原 Platform 的 Shell、写源码、后台调度、Subagent 工具。

新增：instructions、analysis（本地提取/匹配/差距）、memory（岗位记录）、tools、permissions（独立权限配置）、runtime（业务配置）、cli、三个 Skill、人工样例与测试。统一入口增加 `--agent job`；状态单独存入 `.agent-platform/job-agent/`。

实施与验收：

1. 三个 Skill 各有可测试的结构化报告和原文依据，未说明字段不猜测。
2. 本地岗位记忆持久化，重复 JD 不重新提取，变更简历重新匹配；JD 提取失败不能写成功岗位记录，后续匹配失败不把整个工作流标为完成。
3. Job Agent 使用同一 SDK Runner，只有自己的工具和会话；只读取用户直接提供的文本文件或粘贴内容。
4. 默认离线规则模式，不上传简历/JD、不收费；真实模式须单独确认数据与费用。
5. 三个 Skill、去重、边界与端到端测试通过，原 Platform 回归通过，README 的启动命令实测。

范围：手动提供 UTF-8 Markdown/TXT；不添加抓取、自动投递、Web UI 或依赖。规则模式是实际文本处理，模型决策由离线替身按固定流程完成；不宣称具备真实 LLM 的语义理解。

## 完成与验证（2026-10-04）

已按以上计划实现。Platform 仅增加业务配置方法、终端业务入口和 SkillCatalog 的相对目录参数，原教学模块保留。

新增 29 项测试覆盖三个 Skill、原文依据、否定/学习/矛盾表达、学历与专业、相关项目经验、岗位持久化和去重、变更简历、Skill 加载与工具隔离、凭据拦截、以及 SDK 离线/模拟 HTTP 工作流。全项目共 272 项测试通过。

实际启动验证：完整人工样例、重复分析、三个单独 Skill、查看岗位、终端导入与多行粘贴、正常退出、原 Platform 单次任务兼容；非交互式真实模式被拒绝。所有真实模型接口仅使用模拟 HTTP 验证，本次没有付费调用或上传源码/JD/简历。

新文件语法、状态忽略规则、Skill 大小限制和修改文件的密钥检查通过；没有安装或升级依赖。默认状态只保留本次人工示例岗位一条，不代表真实招聘信息。

## 核心业务闭环补齐（2026-10-04）

检查结果：统一入口、三个 Skill、岗位去重、背景匹配与权限隔离已有实现；交互仍要求记住多个命令，差距报告没有集中列出已有能力与最先处理的动作。

本次修改限于 Job 业务层、相关测试和 README：

1. 默认启动后引导输入一次个人背景，直接粘贴 JD，`.end` 后自动执行三个 Skill；可连续分析岗位并复用本次背景。旧命令保留，增加仅提供 `--resume` 文件后交互输入 JD 的用法。
2. skill-gap-analysis 增加有简历证据的已有能力及最多三项优先动作；必需优先，同级明确差距、学习中、待确认依次处理。
3. 补充常见招聘标题与无标题职责识别，修正同一行“必需技能 + 优先技能”的提取。提取版本升级为 2，旧岗位在同一编号上更新一次，保留来源/首次记录时间，不插入重复岗位。
4. 粘贴支持取消，空材料、疑似凭据和未以 `.end` 完成的输入不会导入或分析。

新增 11 项测试；目前 Job Agent 40 项、全项目 283 项全部通过。真实解释器启动验证：直接粘贴背景与两个重复 JD、背景文件后粘贴 JD、仅分析 JD、旧文件入口及原 Platform 入口均通过。测试只使用人工材料、本地运行或模拟 HTTP；本次无依赖变动、收费调用和外部上传。

仍是本地词典与规则分析，复杂语义和条件需复核，不把关键词证据或覆盖率当作熟练程度/录用概率。完整简历不自动归档，背景在当前进程内复用，会话仍保存必要分析证据片段。
