# Job Agent v5：每日 local 更新

## 复用与范围

入口仍是 `main.py --agent job`，不增加第四个业务 Skill。复用 `search_cli.collect_search`（从 v3 原入口提取的共同函数）、公开来源解析和城市阶段搜索、`DiscoveryStore`、`analyze_candidates`、三个 Skill、证据边界、评分及 v4 `JobLibrary`。

`background_tools.BackgroundCallbacks` 继承现有后台管理器，复用任务状态查询、结果和退出清理；`scheduled_tools.ScheduledCallbacks` 继承现有定时管理器，复用不提前启动、异步 worker、状态查询和取消。callback 只来自宿主 Python 代码，不向模型暴露任意执行工具；原整数练习入口和原有时间/输入限制不变。业务管理器只在内存保留当前任务，历史进入 SQLite。

v5 固定创建 `mode=local` 的独立分析 Runtime。CLI 拒绝 `--mode llm`、`--model`、`--llm-dry-run`；不初始化 LLMAnalyzer，不设置自动付费确认，也不实现每日 LLM 预算。没有新增依赖、Skill、Plugin、MCP 或操作系统服务。

## 每日计划与重启

- `--watch --daily-at 09:00` 显式启用当前进程的每日检查，时间固定为北京时间。
- 调度器使用现有 asyncio 计时器，最多每 60 秒重读保存的到期时间，任务到期后交给后台管理器。定时器不阻塞输入。
- `job_daily_schedule` 保存每日时间、下次 UTC 到期时间、最近发现新岗位时间。使用 UTC 保存，按北京时间展示与划分“今日”。
- `job_update_runs` 保存每次检查开始/结束时间、触发方式、状态及结构化摘要；`job_update_items` 连接检查与稳定岗位编号，区分新增、JD 更新和补齐待分析。
- 同一状态目录重启 `--watch` 可不再传 `--daily-at`，保留原到期点。退出后不运行；计划保存在数据库不代表进程正在运行。电脑关机或进程退出期间不会搜索。
- 重启时若已错过到期点，只补查一次，然后安排下一个未来日期，不为漏掉的每一天连续补跑。被中断的检查标记 `interrupted`，保留已有岗位和进度。
- 每日到期点通过 SQLite 条件更新认领；同一状态目录的检查另有文件排他锁，阻止多个进程同时搜索/分析。手动 `/check-now` 不消费或修改每日到期点；跨越到期点时待手动任务结束后再进行当日定时检查，未变化岗位仍跳过分析。计时器自身失败时停止当前调度并提示，保留计划供重新启动，避免到期点上忙循环重试。

## 检查闭环与去重

1. 只读取用户显式指定的简历路径及来源配置，复用原文件安全检查；计划不存简历全文。每次检查重新读取指定文件。
2. 使用 v3 的公开读取、robots、无登录/验证码绕过及请求限制；城市策略仍为广州 >>> 上海 > 深圳，按有效候选不足依次扩展。以 JD 实际工作地点为准。
3. 本地过滤、跨来源去重并取得 v4 稳定岗位编号；保存新 JD 时保留状态、投递时间和备注。
4. 对完成过分析且 JD 未变化的岗位，分析前直接跳过；不因为换简历或缓存上下文改变而自动重分析。需要按新简历重评时仍使用原单份分析入口。
5. 只分析新增、JD 实质变化，以及上次额度限制/中断留下的未完成项。成功分析但没有技术要求时匹配度为“不适用”，不当成未完成反复分析。
6. 沿用 `--search-limit`（默认 8，最多20）和 `--analyze-limit`（默认2，最多5）。未分析岗位保留为待分析；下一次额度内补齐，不能把缺少分数解释成匹配度0%。
7. local 未完成的分析标记可以在下一次检查释放并尝试一次，不改变 v3/LLM 的防重复付费语义，不在同一次检查内无限重试。
8. 保存摘要与来源错误。全部来源失败标记 `failed`，部分失败标记 `partial`，不把读取/解析失败当成成功的“零新增”。检查有600秒总时限。失败不立即自动重试，等待下一次计划或手动检查。

## 摘要含义

本次摘要列出新增、JD 更新和补齐分析的公司、岗位、工作城市、匹配度、推荐等级及原始链接；推荐统计以这些本次更新项为范围。历史检查摘要保留当时的结论，`/new-jobs` 从北京时间今日首次发现的稳定编号去重，展示当前最新信息和评分。最近一次发现新岗位时间只在真正新增时更新，重复或仅 JD 变化不刷新。

测试使用可控时钟、人工简历/JD、离线 fixture 和 HTTP mock，不真实等待一天，不发真实招聘网络请求或付费模型请求。不自动投递、登录、发邮件或修改简历。
